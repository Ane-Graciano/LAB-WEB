# CRUD Node.js + MongoDB + React

CRUD básico de produtos.

## Backend

Node.js + Express + TypeScript + Mongoose.

## Frontend

React + Vite + TypeScript.

## MongoDB

Por padrão:

mongodb://127.0.0.1:27017/crud_node

## Executar

Na raiz:

npm install

npm run install:all

npm run dev

Frontend:

http://localhost:5173

Backend:

http://localhost:3000

Health check:

http://localhost:3000/api/health
